HTML TAGS AND ATTRIBUTES
- <!DOCTYPE html>: declares an HTML5 document.
- <html lang="en">: root element and document language.
- <head>: contains page metadata and linked resources.
- <meta charset="UTF-8">: sets character encoding.
- <meta name="viewport"...>: helps the page scale on mobile screens.
- <title>: text shown in the browser tab.
- <link rel="stylesheet" href="style.css">: loads the separate stylesheet.
- <body>: contains visible page content.
- <header>: introductory page content.
- <nav>: navigation links.
- <main>: main content area.
- <section>: groups related content.
- <footer>: closing page information.
- <h1>, <h2>, <h3>: headings at different levels.
- <p>: paragraph.
- <ul>: unordered/bulleted list.
- <ol>: ordered/numbered list.
- <li>: an item inside a list.
- <dl>: description list container.
- <dt>: term in a description list.
- <dd>: description/details for a term.
- <a href="#unordered">: internal link to the element whose ID is unordered.
- target="_blank": requests opening a link in a new tab/window.
- rel="noopener noreferrer": security/privacy attributes for new-context links.
- start="5": starts ordered list numbering at five.
- type="I": uses uppercase Roman numerals for ordered-list markers.
- id: unique element identifier.
- class: reusable CSS grouping label.
- <!-- comment -->: developer note not displayed as webpage content.

CSS CONCEPTS
- body: element selector for global typography, background, color and spacing.
- .header, .navigation, .content, .footer: class selectors.
- .navigation a: selects links inside navigation.
- :hover: styles an element when the pointer is over it.
- font-family: chooses the text font.
- background-color and color: set background and text colors.
- margin: outer spacing.
- padding: inner spacing.
- max-width: limits content width.
- border and border-radius: outline and rounded corners.
- text-align: aligns text.
- line-height: controls line spacing.
- padding-left on lists: controls indentation.
- display: inline-block allows navigation links to sit next to each other.
- @media (max-width: 600px): applies responsive styles to narrow screens.
