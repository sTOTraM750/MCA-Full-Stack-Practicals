
PROGRAM 1: BCA SIX-SEMESTER MARKSHEET

Objective:
To design a professional academic marksheet using HTML and CSS.

Files:
1. index.html - Contains student details, six semester tables, final result, signatures, and footer.
2. style.css - Contains layout, table formatting, responsive styling, and print styling.

Concepts Demonstrated:
- HTML document structure
- Semantic HTML elements
- Tables with thead, tbody, and tfoot
- CSS classes and selectors
- Borders, padding, margins, and colors
- Flexbox for signature positioning
- Responsive media queries
- Print-friendly A4 layout

Note:
All student details and marks are fictional sample data.
This project is for educational demonstration only.
